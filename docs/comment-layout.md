# 评论布局

全局配置：

```yaml
waline:
  layout: slide # slide 侧滑面板 / bottom 正文底部（主题默认）
```

文章和独立页面的 front matter 均可覆盖：

```yaml
comment_layout: bottom
```

使用现有 `comment: false` 关闭该页评论，评论区和工具栏评论按钮一起隐藏。未渲染评论区的首页、归档等页面也不显示按钮。

支持评论的正文底部显示轻量互动入口，点击“查看评论”打开侧栏或滚动至底部评论区。Waline 返回总数后同步显示数量，首次加载前不显示占位 0；手机端上下排列，入口与评论共用开关。

侧滑面板跟随 `sidebar.position`（头像/侧栏所在侧，工具按钮对侧），不单独配置方向。点击评论按钮打开，支持关闭按钮、Esc、点击遮罩关闭；窄屏占满屏宽，减少动态效果设置下关闭动画。

`#comments` 和评论 ID 深链接会打开面板并加载评论；目标出现后滚动定位。数字 ID 不再被当作 CSS 选择器；底部模式同样支持异步定位。目标不在已加载内容中时依次加载更多评论，目标不可见时提示。保留普通正文锚点行为，并在 PJAX 离开页面时销毁面板和监听。

改动后运行博客根目录 `pnpm run theme:build`，重新生成站点并重启本地 Hexo 服务。

向下滚动至“加载更多”距离可视区域底部 20% 屏高以内（最小 120px、最大 240px）时，自动点击原生按钮。侧滑以面板为滚动区域，底部模式以窗口为准；需滚轮、触摸或键盘向下操作，程序定位、打开面板及图片排版变化不会自行触发。每轮仅请求一页，返回后需继续向下操作；失败不自动重试，可手动点击原按钮。

头像及正文图片加载、解码后以 0.8 秒模糊变清晰效果显现，参考 Lavender 站点的图片过渡；不额外叠加头像外层遮罩。页尾最新评论头像和文章正文复用同一套效果，已经加载或快速从缓存可用的图片直接显示，不重复播放模糊动画。离屏懒加载图片接近视口才开始计时，失败或等待超过 8 秒解除模糊。深链接先滚动到目标，再只等待目标评论自身的头像和正文图片（不包含子回复或其他评论）及显现动画，布局更新后再次对齐并播放头像定位提示。关闭、切换目标或离开页面会取消旧提示；减少动态效果模式不播放显现和定位动画。
