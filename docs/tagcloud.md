# 标签云

标签页支持文章数量角标、按数量分级的字号与配色，以及可选的旋转 3D 标签云。配置位于主题 `tagcloud`，站点可通过 `_config.shokax.yml` 覆盖：

```yaml
tagcloud:
  mode: 2d          # 2d | 3d，初始视图
  switchable: true  # false 隐藏切换按钮并固定初始视图
```

`min`、`max`、`start`、`end`、`amount` 继续控制字号、颜色和标签数量。文章数量由 Hexo 标签数据直接生成；名称经 Pug 转义，链接经过 `url_for`。

访客切换只作用于当前页面实例，重新进入标签页采用配置的初始视图。没有 JavaScript 时，两种配置均降级为完整的 2D 链接列表。

切换视图时，标签从当前屏幕位置过渡至球面或平面位置；快速切换可中断并接续过渡。右侧紧凑图标切换器约 31px 高。

3D 标签的基础字号同样由文章数量决定，再叠加前后景透视缩放。悬停放大与上浮仅作用于内部 `.tag-cloud-label`；内部文字不参与鼠标命中，外层链接保持固定命中区域，避免标签边缘反复进入/离开导致旋转抽动。

3D 模式根据鼠标相对球心的方向进行双轴旋转，距离越远速度越快（有上限），移出球体和标签云区域仍会跟随；离开浏览器页面后缓慢恢复默认转速。悬停具体标签或键盘聚焦时暂停，标签放大、上浮并提亮。3D 标签禁止文本框选和原生链接拖拽，正常点击和键盘导航保留。页面不可见或标签云离开视口时暂停。系统开启减少动态效果时关闭切换动画和自动旋转。PJAX 切页重新初始化前会清理上一实例的动画、监听和观察器。无额外运行依赖。
