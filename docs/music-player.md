# 音乐播放器

主题 YAML：

```yaml
modules:
  player: true
  pjax: true
playerAPI: https://your-meting-api.example/meting-api/api
audio:
  - title: 我的音乐
    list:
      - https://y.qq.com/n/ryqq/songDetail/003jjoM94WLiTf
      - https://music.163.com/#/playlist?id=2943811283
```

`playerAPI` 是完整 HTTP(S) Meting 入口，支持部署子路径和已有查询参数。
仅填写域名时，为兼容旧配置补 `/meting/`。服务器必须允许站点 Origin 跨域访问。
支持接口返回 `{ title, author, url, pic, lrc }[]`，也兼容 `{ name, artist, url, pic, lrc }[]`；
统一转换为播放器内部字段。主题不会自动回退到另一个服务。

本地调试可通过 Hexo 环境覆盖设置 `configuration_mode: local` 和
`theme_config.playerAPIKey`，请求用 Authorization Bearer 发送。其他模式不向浏览器输出 Key。
正式站使用 API 来源白名单。本站通过 `toolbox/configuration/config.yml` 保存本地 Key 并生成覆盖，
production 清空字段，发布前检查产物，具体流程见博客的配置工具说明。
API Key 查询返回的临时音频、封面和歌词链接可直接使用；15 分钟后需刷新页面重新查询。

页面初始化只绑定入口，不查询音乐接口。首次点击立即显示面板占位内容，播放器代码异步挂载后开始查询；面板展开不等待歌曲请求完成。可在挂载期间关闭面板或取消播放意图，操作不会因加载结束而被撤销。

歌单每个配置来源预留一行，优先开始默认来源；其余仅请求当前分组可视区域及上下各 3 条（按实际行高计算）的来源。滚动、列表更新、尺寸变化和 IntersectionObserver 通知共同触发实际位置核对，按来源标识统一维护请求池，避免过期观察通知或 DOM 替换漏掉可见行。未打开的分组和范围外保留待加载占位；离开范围时撤销尚未开始的排队请求，已开始的请求正常完成并保留结果。最多四个请求在途，每次查询间隔 150ms。返回一批就填入对应位置；单曲链接逐首出现，歌单链接一次填入多首。歌曲按配置顺序排列、组内按音频 URL 去重；更新保留当前歌曲对象与选择，前面的来源插入多首不会重置音频、进度或播放状态；列表按首个可见稳定行保持滚动位置。

面板和桌面控制器共用切歌逻辑：上一首／下一首按当前分组更新后的 index 前后循环，随机模式从当前分组抽取目标（包含待加载来源）。遇到占位时优先请求并等待，不受可视范围撤销影响；返回 playlist 后先展开，下一首取其中第一首、上一首取最后一首、随机从返回歌曲中抽取。明确空结果、请求错误或本次等待超过 15 秒后才尝试下一个候选；候选耗尽则暂停，避免无限循环。连续切歌或手动选歌使旧操作失效，迟到响应只更新列表，不抢回播放。窗口外已加载结果保留，下次进入不重复请求。

集合来源例外：使用与 API 请求相同的 parseMusicSource 分类，`playlist`、`album`、`artist` 一旦入队即保留任务，移出范围也不撤销，因为其返回结果会展开列表并修正后续编号。尚未触发的集合仍保留占位；`song` 继续按窗口撤销未开始的请求。返回时立即按稳定歌曲标识恢复选中位置，并保持当前视窗锚点；若切歌等待期间其他来源已展开，后续候选按来源标识重新查找，避免用旧索引跳过歌曲。类型对应 [Meting-API 接口文档](https://github.com/zhangyxXyz/Meting-API/blob/main/docs/API.md)。

重新打开面板或切换当前歌曲时，列表切回当前歌曲所在分组，并将不可见的选中行滚入列表视窗（尽量居中，首尾受边界限制）。异步返回与分组过渡完成后按歌曲 key 定位；普通加载、播放进度更新和暂停／恢复不会触发定位。用户在定位完成前滚轮、触摸、按键或按下鼠标会取消这次定位，之后可以自由浏览；只滚动歌曲列表，不移动整页。

单请求 15 秒超时，429 或网络失败最多退避重试两次，403 等鉴权失败不重试。待加载／加载中／失败占位显示圆点，但仍保留一个编号位置，避免快速滚动后编号变成已加载歌曲的累计数；失败项取消上游划线样式。接口明确返回空数组或没有可播放歌曲时，移除该来源占位；网络／HTTP／响应格式错误则保留失败来源在原位置，单击或键盘激活即可仅重试该来源，其他歌曲照常使用；空分组不显示。

默认选择等待前面的来源完成或失败，再选择按配置排序的第一首可用歌曲；用户可先播放任何已就绪歌曲，后续结果不会抢走该选择。默认歌曲就绪且面板展开时，加载其封面和歌词；面板未播放也显示歌词预览，切歌清空旧歌词并隔离迟到响应。

现有 API 返回的媒体地址随元信息一起保留，但音频元素不设置 src，直到用户实际播放选中歌曲（preload=none）。提前点击播放会记录意图，默认歌曲就绪即播放，不等待完整歌单；再次点击可取消。暂停保留已加载歌曲；全页刷新重新查询临时地址，不自动续播。

桌面端双击其他歌曲开始播放，单击其他歌曲不会打断当前歌曲；键盘聚焦其他条目后可按 Enter／空格播放，触屏设备单击播放。激活其他歌曲从 0 开始，包括切回之前播放过的歌曲。
当前歌曲已取得时长后整行只用于调整进度：单击立即跳转，拖动松开后提交；双击不会重播，也没有区分单双击的等待。填充在按下／拖动时预览目标位置，提交后保持至播放器完成更新，避免「目标→旧位置→目标」闪动。悬停提示目标时间／总时长，与填充预览使用独立位置变量。
暂停时也可调整，保持暂停状态；播放／暂停按钮用于断点续播。Escape、失焦、滚动、切歌或收起面板取消拖动；触屏允许纵向滚动歌单，取消手势不跳转。方向键调整 5 秒，Home／End 到首尾；当前滑块的 Enter／空格不触发歌曲重播。无有效时长时保留原歌曲激活方式，切歌后的过期跳转不会写入新音源。
喇叭按钮正下方的细音量条默认 60%，可拖动或用方向键调整，并通过 `shokax.music.volume` 在本机记住设置。
喇叭按钮用于静音／恢复声音；页面切换不重置音量，浏览器存储不可用时仍可正常调节。音量条悬停提示目标位置的百分比，按滑块圆点实际行程计算；拖动和键盘调整显示当前百分比，移出、失焦或收起面板后隐藏。

播放器每个文档只初始化一次。启用 `modules.pjax` 后，站内切页保留同一个播放器和 audio 节点，
歌曲、进度、音量及播放状态不变，浏览器前进／后退也可连续播放。路由及统计兼容见 [无刷新切页](navigation.md)。
播放进度始终从原生 audio 时钟读取；移除 Nyx 在 pathname 改变时回写旧进度的逻辑，避免切页触发 seek 卡顿。
切换音源时同步清零播放器进度、时长与原生音频位置，并重新加载音源；忽略旧音源或尚未就绪的进度事件。
切回曾播放过的歌曲同样从头开始；暂停后继续当前歌曲以及 PJAX 切页保留原进度。
显式重播会保护第一次 `playing` 事件结束后的起始位置，纠正媒体增强脚本在该事件中恢复旧进度的冲突；保护结束前不将异常进度写入歌单，避免误触发下一首。仅保护本次加载启动，正常暂停续播不重新归零；手动调整进度取消尚未结束的启动保护。
手动刷新、离站或禁用 PJAX 的页面仍会整页加载；整页重载重新获取音频地址并清除
Nyx 旧播放缓存，避免缓存失效 URL 或未经点击续播。音频不可播时暂停并显示提示，用户可换曲；不保证第三方 API
返回完整音频，部分链接可能只提供试听。

保留 `nyx-player@0.1.1` UI，通过 `scripts/utils/music-player.ts` 的 esbuild 适配器替换
歌单解析，并处理 `play()` 拒绝／原生音频错误。适配器校验上游代码形状，升级依赖时必须复核。
不直接修改 node_modules 或生成目录。主题颜色和工具栏位置适配在 `outline/header/tool.styl`，
首页同样加载，播放面板显示在看板娘之上。

歌词适配忽略标题、作者等 LRC 元信息，支持同一行多个时间戳、偏移值与同时间翻译合并；
按时间排序。空歌词或获取失败不影响音频播放，也不抛出阻断面板的解析异常。
桌面歌词开关开启且音乐正在播放时，页面底部显示当前句和下一句两行悬浮歌词；面板展开或收起不影响显示。关闭歌词开关、暂停或没有当前歌词时隐藏。
两个视图共用有界缓存中的请求和解析结果，跟随原生音频时间；切歌后的旧异步结果不会覆盖新歌词。
桌面视图跳过 LRC 的空白时间戳，间奏保留当前句并预告下一条非空歌词，避免误切成单行或隐藏控制栏。
真正最后一句居中保留至歌曲结束；首句尚未开始时不提前显示。
浮层由左侧黑胶唱片、中间双行歌词和右侧收起图标组成，窄屏避开底部工具栏。
短句使用较短的胶囊，长句按内容扩展至屏幕允许的上限，超过上限单行省略。
宽度通过逐帧指数插值趋近内容宽度（时间常数 110ms），中途更新目标继续从当前宽度过渡。到位即停止帧循环；后台、隐藏和减少动态效果时直接到位，窗口缩放与字体加载后重新测量。
唱片使用当前歌曲封面，播放且浮层可见时旋转；暂停、浮层隐藏或后台标签页时停止旋转。
当前句左对齐、下一句右对齐；切句时下一句斜向左上接位，旧句斜向右下淡出，新句错开进入第二行。
长句单行省略，末句不虚构下一句。切句、显示和唱片旋转遵循减少动态效果设置。
胶囊右侧两个无背景按钮沿同一竖线排列，上方 `i-forward` 切歌，下方 `i-chevrons-left` 收起。
切歌无需展开面板；收起只隐藏桌面控制栏，不暂停或跳转歌曲。
控制栏使用七列等宽布局，顺序为播放模式、桌面歌词、上一首、播放/暂停、下一首、可视化、音量。普通图标 20px，居中播放键的圆形图标约 28px，所有按钮高度 40px；音量滑杆位于音量图标下方。
播放器控制栏通过 `i-desktop-lyrics-off` / `i-desktop-lyrics-on` 图标切换桌面歌词，开启时为主题粉红；按钮悬停提供说明。
关闭后播放继续，播放中重新启用时恢复显示；仅有一句歌词时在胶囊内双向居中。
随机模式按随机逻辑选曲，顺序与单曲循环模式手动切至下一首。
可见时整条控制栏接收鼠标事件，避免悬停和点击穿透到下方链接；隐藏时不阻挡页面。
唱片、歌词与控制按钮共用一层半透明毛玻璃底板；歌词区完全透明，不再保留内层胶囊。
浮层采用常规字重，当前歌词与右侧按钮使用主题粉，当前句叠加低透明度的同色文字阴影；下一句保持灰色、无阴影。收起提示支持行内 iconfont，默认展示桌面歌词按钮图标，语法见 [主题悬停提示](tooltips.md)。工具栏高于看板娘，避免窄屏点击被遮挡。
交互参考 [Lavender 的桌面歌词文章](https://blog.lavender816.top/posts/1882074506/)，实现适配本主题的 Nyx 播放器。

桌面歌词条默认短句宽度缩短约 20%，歌词两侧留白收紧；桌面底部间距为 `.5rem`，
唱片直径为 `3rem`，整体约 `3.375rem + 2px` 高。窄屏继续避开底部工具栏。

音乐可视化参考 [Lavender 的音乐音效可视化](https://blog.lavender816.top/posts/3257086419/)，
在 `components/music-visualizer.ts` 中独立实现，复用当前 audio 和 `#waves`，不引入新依赖。
控制栏使用 `i-audio-visualizer` 图标，开关保存到 `shokax.music.visualizer`，默认关闭。
开启且播放时，以樱粉、浅紫、薄荷青三层平滑曲线替换 SVG 波浪；暂停或关闭时恢复原波浪。
Canvas 按需创建，30 FPS、DPR 上限 2；后台和减少动态效果时停止绘制。
页头波浪滚出视口上方后，约 400ms 淡入贴底波浪，并从底边上移 12px；页头重新露出至少 12% 时切回，
通过回切阈值避免边界抖动。底部高度桌面 72px / 窄屏 56px，加安全区，低于歌词/工具栏/Live2D，且不接收鼠标事件。
两处共用同一分析器、曲线相位和 rAF；底部只缩放复制已绘制帧，退出淡出后停止复制，无第二路音频。
暂停或关闭时两处同时淡出；快速滚动、窗口缩放及 PJAX 不重复创建底部 Canvas。
页头和播放器都在 PJAX 替换区域之外，切页不重复创建音频、Canvas 或监听器。

分析采用 `captureStream` 的音频副本接入 AnalyserNode，不将原播放器改接 Web Audio，
不接通第二路声音。音源先以匿名 CORS 加载以支持频谱；若被拒绝则自动以普通音频重试一次，
切歌重新尝试 CORS，旧播放 Promise 不得中断新曲目。支持且允许捕获的音源使用实际频谱；
跨域受限、无捕获 API 或持续取不到数据时使用轻柔的氛围动画，不能将该后备动画当成真实频谱。
切换音源释放旧流并重连；关闭、离页、销毁释放捕获轨道。自动测试覆盖真实/静默频谱分支、
单帧循环、切歌、PJAX、顶部/底部交接、边界抖动、后台/减少动态效果、存储和清理。
