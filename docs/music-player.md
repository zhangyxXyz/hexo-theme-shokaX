# 音乐播放器

主题 YAML：

```yaml
modules:
  player: true
  pjax: true
playerAPI: https://your-meting-api.example/meting-api/api
audio:
  - title: 我的音乐
    list:
      - https://y.qq.com/n/ryqq/songDetail/003jjoM94WLiTf
      - https://music.163.com/#/playlist?id=2943811283
```

`playerAPI` 是完整 HTTP(S) Meting 入口，支持部署子路径和已有查询参数。
仅填写域名时，为兼容旧配置补 `/meting/`。服务器必须允许站点 Origin 跨域访问。
支持接口返回 `{ title, author, url, pic, lrc }[]`，也兼容 `{ name, artist, url, pic, lrc }[]`；
统一转换为播放器内部字段。主题不会自动回退到另一个服务。

本地调试可通过 Hexo 环境覆盖设置 `configuration_mode: local` 和
`theme_config.playerAPIKey`，请求用 Authorization Bearer 发送。其他模式不向浏览器输出 Key。
正式站使用 API 来源白名单。本站通过 `toolbox/configuration/config.yml` 保存本地 Key 并生成覆盖，
production 清空字段，发布前检查产物，具体流程见博客的配置工具说明。
API Key 查询返回的临时音频、封面和歌词链接可直接使用；15 分钟后需刷新页面重新查询。

每组读取全部链接，兼容 QQ 的 `songDetail` 与旧 `song/*.html`，以及网易云普通／hash 链接。
最多四个请求在途、每次开始查询间隔 150 ms、单请求 15 秒超时；429 或网络失败最多退避重试两次，
403 等鉴权失败不重试。按配置顺序合并，以音频 URL 去重。单条失败不拖垮其他来源，
空分组不显示；全部失败时工具按钮可点击重试。加载不阻塞页面其他组件，默认不自动播放。
初次只请求歌单元信息；音频使用 `preload=none`，点击播放后才加载，播放中切歌自动加载所选歌曲。
封面和歌词在展开播放器或开始播放时请求，不预先下载整组歌曲的音频或歌词。
桌面端双击歌单条目开始播放，单击不会打断当前歌曲；键盘聚焦条目后可按 Enter／空格播放，
触屏设备单击播放。激活歌曲总是从头开始，包括再次双击当前歌曲；播放／暂停按钮才用于断点续播。
歌曲行不显示额外的聚焦边框或操作提示气泡，当前曲目沿用播放器原有高亮。
喇叭按钮正下方的细音量条默认 60%，可拖动或用方向键调整，并通过 `shokax.music.volume` 在本机记住设置。
喇叭按钮用于静音／恢复声音；页面切换不重置音量，浏览器存储不可用时仍可正常调节。

播放器每个文档只初始化一次。启用 `modules.pjax` 后，站内切页保留同一个播放器和 audio 节点，
歌曲、进度、音量及播放状态不变，浏览器前进／后退也可连续播放。路由及统计兼容见 [无刷新切页](navigation.md)。
播放进度始终从原生 audio 时钟读取；移除 Nyx 在 pathname 改变时回写旧进度的逻辑，避免切页触发 seek 卡顿。
切换音源时同步清零播放器进度、时长与原生音频位置，并重新加载音源；忽略旧音源或尚未就绪的进度事件。
切回曾播放过的歌曲同样从头开始；暂停后继续当前歌曲以及 PJAX 切页保留原进度。
手动刷新、离站或禁用 PJAX 的页面仍会整页加载；整页重载重新获取音频地址并清除
Nyx 旧播放缓存，避免缓存失效 URL 或未经点击续播。音频不可播时暂停并显示提示，用户可换曲；不保证第三方 API
返回完整音频，部分链接可能只提供试听。

保留 `nyx-player@0.1.1` UI，通过 `scripts/utils/music-player.ts` 的 esbuild 适配器替换
歌单解析，并处理 `play()` 拒绝／原生音频错误。适配器校验上游代码形状，升级依赖时必须复核。
不直接修改 node_modules 或生成目录。主题颜色和工具栏位置适配在 `outline/header/tool.styl`，
首页同样加载，播放面板显示在看板娘之上。

歌词适配忽略标题、作者等 LRC 元信息，支持同一行多个时间戳、偏移值与同时间翻译合并；
按时间排序。空歌词或获取失败不影响音频播放，也不抛出阻断面板的解析异常。
播放面板收起且音乐正在播放时，页面底部显示当前句和下一句两行悬浮歌词；展开面板、暂停或没有当前歌词时隐藏。
两个视图共用有界缓存中的请求和解析结果，跟随原生音频时间；切歌后的旧异步结果不会覆盖新歌词。
桌面视图跳过 LRC 的空白时间戳，间奏保留当前句并预告下一条非空歌词，避免误切成单行或隐藏控制栏。
真正最后一句居中保留至歌曲结束；首句尚未开始时不提前显示。
浮层由左侧黑胶唱片、中间双行歌词和右侧收起图标组成，窄屏避开底部工具栏。
短句使用较短的胶囊，长句按内容扩展至屏幕允许的上限，超过上限单行省略。
唱片使用当前歌曲封面，播放且浮层可见时旋转；暂停、展开面板或后台标签页时停止旋转。
当前句左对齐、下一句右对齐；切句时下一句斜向左上接位，旧句斜向右下淡出，新句错开进入第二行。
长句单行省略，末句不虚构下一句。切句、显示和唱片旋转遵循减少动态效果设置。
胶囊右侧两个无背景按钮沿同一竖线排列，上方 `i-forward` 切歌，下方 `i-chevrons-left` 收起。
切歌无需展开面板；收起只隐藏桌面控制栏，不暂停或跳转歌曲。
播放器控制栏的“词”按钮用于开关桌面歌词，开启时显示边框；按钮悬停提供说明。
关闭后播放继续，重新启用且收起播放器时恢复显示；仅有一句歌词时在胶囊内双向居中。
随机模式按随机逻辑选曲，顺序与单曲循环模式手动切至下一首。
可见时整条控制栏接收鼠标事件，避免悬停和点击穿透到下方链接；隐藏时不阻挡页面。
唱片、歌词与控制按钮共用一层半透明毛玻璃底板；歌词区完全透明，不再保留内层胶囊。
浮层采用常规字重，文字颜色随主题调整；工具栏高于看板娘，避免窄屏点击被遮挡。
交互参考 [Lavender 的桌面歌词文章](https://blog.lavender816.top/posts/1882074506/)，实现适配本主题的 Nyx 播放器。

验证：`pnpm test`（主题目录）与 `node toolbox/test-music-player.mjs`；博客构建使用根目录
`pnpm run theme:build` / `pnpm run build:local`，不要执行主题上游 `pnpm build`。
