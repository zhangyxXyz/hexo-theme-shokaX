# 友链评论标签

```yaml
waline:
  friendBadge:
    enable: true
    source: friend-links/_data.yml
    colors:
      light: { text: '#347d83', background: '#eaf5f4', border: '#c5e3df' }
      dark: { text: '#9ad5ce', background: '#253b3c', border: '#3d6262' }
```

主题默认关闭。开启后，构建时读取相对于博客 `source` 的 YAML 友链列表（每项的 `url`），不额外请求服务器。关闭设为 `false`，修改名单或配置后重新生成站点并重启开发服务。

`colors` 可分别设置亮色和暗色模式下的文字、背景、边框色，接受带引号的十六进制颜色。省略时使用柔和青色；仅影响客户端友链标签，原生身份标签保留主题配色。

评论没有原生标签或管理员标识时，昵称附带的网站命中名单就显示“小伙伴”；文案来自语言文件 `comment_friend`，外观复用主题评论标签。它仅表示网址匹配，不证明评论者身份。

只匹配 HTTP/HTTPS 地址，忽略协议、查询参数和片段；域名及非默认端口必须一致，不自动合并 www 或子域名。名单含路径时，只匹配该路径及其子路径，避免共享博客平台不同账号误匹配。不要用评论正文中的链接判断身份。

支持异步加载、排序、分页和 PJAX；已有原生标签优先，客户端标签不会修改评论数据。
