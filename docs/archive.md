# 归档视图

归档页支持「时间树」与「经典归档」两种显示方式。两种视图共用「首页 / 目前共计 N 篇文章」页头，保留首页链接和原站点侧栏，与标签页的标题结构一致。时间树以年份为章节、月份为卡片，宽屏沿中央时间轴交错排列；经典归档保留原有的年月归档样式。右侧图标胶囊可随时切换视图，图标附带悬停提示与无障碍名称。经典模式下胶囊位于页头右侧，不占独立行高，标题圆点以虚线连接首个归档节点。

## 配置

在站点的 `_config.shokax.yml` 中覆盖主题配置：

```yaml
archive_view:
  mode: tree
  switchable: true
```

`mode` 可设为 `tree` 或 `classic`，默认是 `tree`。`switchable: true` 显示切换按钮，并通过当前站点的 `localStorage` 键 `shokax.archive.mode` 记住访客选择；下次进入归档页时，已保存的选择优先于 `mode`。

设为 `switchable: false` 时隐藏切换按钮，忽略访客此前保存的偏好，始终使用配置指定的模式。例如固定使用经典归档：

```yaml
archive_view:
  mode: classic
  switchable: false
```

## 时间树交互

- 月份卡片按每页 5 篇独立翻页，翻页不跳转页面、不改变其他月份。「展开全部／返回分页」与「本月归档」并排放在卡片底部操作栏，完整展开时隐藏页码行，返回时恢复此前页码。
- 总归档默认展开最近三个有文章的年份，较早年份折叠；年度、月度归档默认展开页面内的所有年份。
- 年份数字链接到对应年度归档，胶囊右侧的篇数与箭头区域用于展开、折叠，也可用「展开所有年份／收起所有年份」批量操作。
- 时光索引定位对应年份，收起的年份会先展开。桌面与手机统一使用正文区域右下角的悬浮年份胶囊，横向位置跟随正文阅读边界，上下位置限制在正文内部：滚动经过正文边界时停靠在该边界，随正文离开视口。点击后向上展开年份选项；选择年份、点击外部或按 Esc 自动收起，调整窗口大小保留展开状态。
- 宽屏卡片外沿、工具栏与页头文字共用左右阅读留白；中等宽度和手机改为左侧单轴。时间树不再为独立年份索引预留一列，原站点侧栏保留。
- 年份与月份展开、收起带高度和方向过渡，遵循系统减少动态效果的偏好。
- 时间树不受整页分页限制：总归档展示全部文章，年度和月度归档展示对应范围的全部文章，按站点时区分组并按日期倒序。经典模式保留原有分页及本页数量，切换视图时同步切换数量说明和页面底部分页。

视图切换只改变显示方式，不改写文章日期、链接或归档数据。归档组件在 PJAX 页面刷新时重新初始化，离开页面时清理监听与待执行任务。

## 无 JavaScript 时

页面使用配置指定的默认视图，不读取已保存的访客偏好。年份采用原生 `details` / `summary`，每个月直接显示全部文章，隐藏需要 JavaScript 的月内分页控件。窄屏年份索引回退为横向列表；文章链接、年度和月份归档链接保持可用。
