# 顶部站名

顶部站名继续使用 `font.logo` 指定的字体。红青分色效果参考 [Lavender's Blog](https://blog.lavender816.top/) 的标题实现：两层装饰文本以红色 `#ff3f1a`、青色 `#00a7e0` 阴影和水平裁切形成错位；只有支持悬停的精细指针设备在悬停或键盘聚焦时播放 0.8 秒切片动画。

模板中的 `.artboard-glitch` 隐藏于无障碍树，不影响标题原文；百分比裁切适配响应式字号。减少动态效果时隐藏装饰层。效果仅作用于站名，不作用于文章标题；页尾站名复用顶部字体与动画，以普通混合模式保留浅色背景上的分色，顶部保留 `lighten` 混合。
