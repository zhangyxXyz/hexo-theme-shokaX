# 图标视觉修正

站点 `source/_data/icon_baselines.json` 集中配置 iconfont 的视觉修正：基线、大小和粗细。所有使用 `.ic` 的图标共用这套规则，包括提示文字、正文混排、导航和工具栏；组件不再单独写图标的 `translateY`、缩放或描边。

```json
{
  "font": "3463079_jxh7qenyna",
  "default": 0,
  "icons": {
    "i-music": 0.08,
    "i-download": { "scale": 1.05, "weight": 0.012 },
    "i-reset": { "baseline": 0, "scale": 0.86, "weight": 0.028 }
  }
}
```

- key 使用完整的 iconfont class。值为数字时只修正基线（旧写法），为对象时可组合三项：
  - `baseline`：图标自身字号的 `em`，**正数下移，负数上移**，范围 `-0.5` 到 `0.5`。例如 `0.05` 在 20px 图标上下移 1px。
  - `scale`：绕字形中心缩放，范围 `0.5` 到 `2`；占位宽度、行高和点击区域不变。
  - `weight`：用 `-webkit-text-stroke` 加粗的额外笔画宽度，单位 `em`，范围 `0` 到 `0.1`。字体字形只能加粗，不能变细；偏粗的图标改用更细的字形或调小 `scale`。
- `default` 同样接受数字或对象，作用于未单独配置的图标。超出范围、非数字和非法 class 不生成 CSS。
- `font` 必须与主题 `iconfont` 项目版本一致；换字体版本后先复核再更新，避免沿用旧字形修正。缺少文件或版本不符时不修正。

构建时 helper 把配置写入页头 `#icon-baselines` 样式，`.ic::before` 统一读取 `--icon-baseline`、`--icon-scale`、`--icon-weight`。只改字形，不改外层图标动画，也不依赖前端 JS，所以动态提示和 PJAX 页面自然复用。修改后重新构建站点。

## 校准

`scale` 也会放大描边，所以 `weight = 目标笔画 / scale − 实测笔画`。参照代码块工具栏的 `i-expand`：可见高度约 0.875em，线性笔画约 0.105em。实测方法：用 `ic` 字体在 canvas 上按 200px 绘制字形，墨迹包围盒得到高度，`2 × 面积 / 周长` 近似笔画宽度。

数值只是起点，最终以实际字号下的并排观感为准：圆、环这类长而连续的轮廓比短线段显重，笔画目标约取 0.09em，并略缩小（约 `0.94`）；把它们拉到和 `i-expand` 相同的 0.105em 会明显发粗。实心图标（如 `i-clipboard`）视觉偏重，只缩小不加粗。

图标预览页的“单行对照”按工具栏密度横排图标，两条横线标出 0.875em 高度；搜索框用空格分隔可同时列出多个图标，“显示修正前”临时关闭全部修正以便对比。卡片底部列出该图标已记录的修正值。

基线已用本站字体在 12px / 24px 文字下校准过歌词开关、可视化、音乐、下一首、双箭头、搜索和爱心；大小与粗细已校准代码块与 Mermaid 工具栏图标。不同字体或字形需要重新校准，几何中心接近不代表不对称图标的视觉重心完全相同。

验证配置：主题目录执行 `node toolbox/test-icon-baselines.mjs`；构建使用博客根目录的 `pnpm run build:local`。
