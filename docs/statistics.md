# 统计页

留言页同样使用 `type: statistics`，在 `#statistics_container` 内组合 `comment-map`、`comment-trend`、`comment-ranking`。代码位于本目录对应的 `components/statistics/comments.ts`、`comment-ranking.ts`、`comment-list.ts`，沿用地图、月份范围、TOP 数量选择器与主题卡片。

评论数据使用 Waline `GET /api/comment?type=statistics`，同页共享一次聚合请求。只包含全站公开且审核通过的评论与回复；地图按评论数量统计，遵循服务端地区显示开关，不把未知地区编造为零。排行支持留言人、内容及文章/独立页面筛选，TOP 10/20/50/全部。内容名称与类型由 Hexo 已发布内容目录提供。

评论排行使用与内容访问排行一致的横向渐变柱状图、整数坐标轴和虚线网格；名称按钮可用键盘打开详情，柱条同样可点击。图表下方说明行中间的“全部公开评论”打开完整列表。

点击排行项打开居中的评论时间线，使用 `type=statistics-comments`，可传 `author`（服务端生成的不透明标识）或 `url`，不传时列出全部公开评论。`page` 从 1 开始，`pageSize` 默认 20、最大 50；响应提供总数、当前页、是否有下一页和评论 ID/路径/昵称/时间，以及可选的公开 `avatar` 地址，不包含邮箱、IP 或私密内容。Waline 服务端需要同步更新头像字段，旧接口或图片加载失败时使用昵称首字头像。

桌面时间线按照返回的时间顺序稳定左右交替，追加下一页不会重排已有条目；手机改为单列。列表按需加载，已知页面链接通过评论锚点定位；未知或站外地址不生成跳转链接。PJAX 离开销毁弹层并取消请求。接口尚未上线时显示失败和重试，不回退虚构数据。

发布趋势提供最近 6/12/24 个月及全部月份，使用通用选择器与 ECharts dataZoom 滑块；拖动后显示自定义，均值只计算可见月份，主题重绘与尺寸变化保留范围。标签数据在生成阶段保留全部，前端提供 TOP 10/20/50/全部，默认 TOP 10，超过十项显示范围滑块。

`clock` 块按已发布文章的发布时间汇总 24 小时极坐标柱图，悬停显示星期分布；使用 Hexo 日期对象中的小时和星期，不将浏览量当作创作量。午夜记录原样保留，因此只填写日期的历史文章可能集中在 00:00。范围滑块与创作时钟的交互参考 https://blog.lavender816.top/statistics/，实现使用本主题模块及粉色配色。

图表统一复用 `tooltip.ts` 的主题提示框。排行链接默认正文色、悬停主题链接色，提示框区分标题与访问量。均值线为低透明度主题粉色细虚线，关闭高亮交互。侧栏一级文字居中，展开线对齐一级图标中轴，二级图标对齐一级文字左沿，各层展开箭头采用统一列位置。

页面 front matter 设置 `type: statistics`。正文的 `#statistics_container` 内放置 `<section data-statistics-chart="posts"></section>` 等占位块；块的选择、数量和顺序由 Markdown 决定。可选值：`calendar`、`map`、`trends`、`sources`（百度）及 `posts`、`tags`、`categories`（站内）。删除百度块后不会发起对应请求。

站点 `_config.shokax.yml` 配置 `statistics.baidu.endpoints/start_date`，以及 `statistics.assets.echarts` 和 `statistics.assets.maps.china/world` 完整资源路径。`endpoints` 是报表接口 URL 列表，兼容旧的单地址 `api` 配置。`statistics.baidu.timeout` 可选，默认 20000 毫秒，无需重复配置。前端不配置或发送 `site_id`，站点 ID 和访问令牌由代理服务管理。`start_date` 决定累计报表的查询起点；资源路径供图表和地图加载使用。站内文章月份起点用页面 `statistics_start: '2018-01'` 配置，未发文月份补零。

多个节点首次并行探测 `new URL('healthz', endpoint)`：`/api` 对应 `/healthz`，以 `/` 结尾的代理挂载路径对应挂载路径下的 `healthz`。健康入口必须支持 CORS 并返回 HTTP 200 和 `{"status":"ok"}`。三秒内先返回有效健康响应的节点优先，其他探测取消；同页图表共享探测，选择缓存于当前会话，禁用 sessionStorage 时使用内存缓存。所有健康检查失败时仍尝试第一个报表接口。报表网络错误、超时、5xx、408、429 或百度临时错误允许切换另一个节点一次，成功后更新选择；鉴权、参数和响应格式错误不切换。PJAX 离开取消探测和请求，不触发故障切换。此机制按实际可达性择优，不判断访客国别。

`scripts/helpers/statistics/site.ts` 在生成时聚合 Hexo 数据。`source/js/_app/components/statistics/baidu.ts` 负责请求，`site.ts` 读取生成的数据，`index.ts` 挂载页面声明的块。`options.ts` 管图表样式，`assets.ts` 管资源加载和地图适配，`map.ts` 与 `map-interactions.ts` 管地图切换和南海命中区域，`panel.ts` 管独立加载/重试反馈。

地图不依赖百度授权成功即可展示。省/国家切换取消旧请求，PJAX 离开清理图表和观察器。南海诸岛按原位完整绘制，透明按钮扩大命中范围，支持鼠标、键盘和点击固定；它没有单独的省级访问量。地图数据的 `center` 映射至 ECharts 4 的 `cp`，保留悬停名称。

地图悬停采用半透明浅橙色和暖色边界，与粉色主导的访问量色阶区分；深色模式适当提高亮度及不透明度。地图和排行榜联动共用此高亮，南海透明命中区不叠加底色。

验证：`pnpm test`，并在页面检查无数据底图、接口失败和重试、地图切换及 PJAX 清理；主题构建请从博客运行 `pnpm run theme:build`，不要在主题源目录运行上游 `build`。

访问趋势使用 `trend/time/a` 的每日 PV，提供 7/30/90/365 天范围，截止昨天，对比前一个等长周期。蓝色实线和淡面积显示本期，灰色虚线按周期内日期序号对齐上期，提示框显示两个实际日期。总量及日均要求本期日期完整；环比还要求上期完整且总量大于零。缺失日期保留空值，不补零。切换取消旧请求，主题重绘、重试及 PJAX 清理沿用统计组件生命周期。

`content` 块提供一个横向条形榜：浏览量（配置起始日期至昨天）/近30天增长（这30天内的新增 PV，不是环比），文章/独立页面，TOP 10/20。使用 `visit/toppage/a` 分页读取完整结果，只接受 Hexo 生成的已发布内容目录中的同主机 URL，忽略查询参数、锚点并合并 index.html 路径。无记录不编造为零；接口忽略分页时显示失败而非不完整排行。当前博客默认展示此块，`trends` 和 `sources` 实现保留，可通过 Markdown 占位块恢复。

地图支持滚轮缩放和拖动，缩放限制为 1–5 倍，线条和南海命中区域同步更新；主题及尺寸刷新保留视角，切换国家/省份重置。`map-ranking.ts` 将当前请求数据按访问量降序展示为地区排行，悬停或聚焦可联动地图；桌面位于右侧，600px 以下默认收起，由右侧双箭头展开毛玻璃浮层。点击外部或 Escape 收起。纵向色阶从浅樱粉过渡到玫瑰粉；CSS 图例与地图使用相同颜色顺序，深色模式单独适配亮度。无数据时隐藏色阶并显示空排行，不把无数据补为零。

排行只显示 Top 10，名称列按最长名称收紧，超过四个字符省略并保留完整提示。桌面排行浮在全宽画布之上，默认视角预留排行空间，缩放后可延伸到浮层下方。滚动条默认透明、滚动时显示主题色细条，停止后淡出。`map-scale.ts` 绘制细条和圆角端点，ECharts 使用相同的主题色阶映射。缩放停止后恢复悬停区域名称与提示，离开区域时清理高亮。

地图工具栏优先与标题同行，空间不足时整组换行，摘要位于下方。工具栏提供地图切换、放大、缩小和复位，使用 `i-plus-circle-outline`、`i-minus-circle-outline`、`i-reset` 图标；按钮与滚轮共用 1–5 倍限制，到达边界禁用对应按钮。复位清除平移和缩放，恢复当前地图初始视角。

各图表采用独立卡片，标题使用主题原生 H1 和独立页面的樱花 anchor 前缀，复用主题字号、默认文字色及标记定位，调整卡片内间距并隐藏 H1 下划线及头部分隔线。缩放工具栏与地图切换采用一致的按钮尺寸和主题强调色状态，空间不足时整体换行。首次加载、重试和切换地图时隐藏排行，成功返回空结果后才展示空状态；加载失败由面板统一显示错误。

地图标题下显示当前范围全部有效记录之和，以及能匹配到底图的不同地区数，未识别的“其他”不计入覆盖地区。排行标题显示实际 TOP 数量（最多 10），桌面排行距地图区域顶部 1rem；切换或重试期间隐藏旧摘要和排行标题。摘要数字使用主题强调色，排行标题、地区提示标题使用适配深浅主题的粉色。无地区记录与测量值 0 使用不同提示。

分类与来源图例由 `legend.ts` 渲染为可横向滚动的按钮列表，不使用 ECharts 分页箭头。滚动条隐藏，与日历共用 `scroll-arrows.ts` 的左右箭头和端点检测。触屏原生滑动，鼠标按住拖动，点击或键盘激活切换分类；拖动超过 5px 后抑制误点击。选择状态在主题和尺寸重绘时保留，PJAX 离开清理观察器。发布量折线与标签柱形采用粉色，面积填充低不透明度，均值线使用低透明度粉色细虚线且无端点箭头，不响应高亮交互；分类色板以粉色为首，辅以可区分的柔和多色，分别适配深浅模式。

访问日历沿用旧站灰色零访问格、粉色色阶和星期日开头的全年网格，起点为一年前所在周的周日。`calendar.ts` 从同一次日数据请求汇总全年、含今天的最近 30 天与 7 天，显示实际统计范围；缺少整个范围的数据用破折号表示。三项汇总在日历卡片底部横排；600px 以下改为一行一项，名称和日期居左、数字居右，仅日历网格横向滚动。日期计算使用日历日而非毫秒差，兼容闰日和夏令时。

内容排行与地图的工具栏优先与标题同行，空间不足时整组换行。内容排行的类型切换居左、排序与 TOP 数量居右；胶囊使用同一套主题状态。TOP 菜单使用通用 `enhanceSelect`，不再伪装成摘要选择器。条形图沿用浅樱粉至玫瑰粉色阶。标题列按当前数据、字体及容器宽度重新测量，文章名称和百度统计来源使用真实链接。内容目录缺失作为初始化错误提示，不再回退空数组误报“暂无统计数据”。

日历网格隐藏横向滚动条，支持触屏滑动、鼠标拖动和左右箭头滚动；无溢出或到达端点时隐藏对应箭头。汇总区域统一使用低不透明度淡粉背景，不再使用横向渐变或模糊边缘，宽屏三列、窄屏一行一项。

评论排行弹窗使用公开评论列表接口。时间线卡片展示真实头像、带站点链接的昵称、专属/等级标签、时间及公开精度的属地、浏览器和系统；昵称悬停显示站点 URL。正文仅重建文本与 HTTP(S) 行内图片，不直接插入评论 HTML；单行省略，字号与普通评论一致，悬停或键盘聚焦显示完整文本（图片用 🖼️ 标识）。正文链接定位到原评论，按文章筛选时标题链接跳转文章。胶囊样式与普通评论一致，配色复用 `waline.levelColors` / `waline.labelColors`，客户端按字段优先于服务端等级/专属标签颜色。需配套支持完整公开字段的 Waline 服务端；旧接口不会用文章标题冒充评论正文。
