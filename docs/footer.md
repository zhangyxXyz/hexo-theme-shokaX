# 页尾

`layout/_partials/footer-discovery.pug` 渲染页尾，`source/css/_common/outline/footer/discovery.styl` 负责响应式样式。外层沿用正文宽度和侧栏预留空间，侧栏仍可固定显示到页面底部。

- 桌面左侧是站点名片、真实字数／阅读时长／访客数据和运行时间；运行天数与时分秒并排，版权位于备案信息上方居中。
- 左栏无独立底色，文字与下方导航对齐；整个页尾以低透明度的静态弧线、星点点缀，不参与鼠标交互。
- 文章、最新评论和储藏间链接统一使用悬停淡入细线框、轻底色与 1px 上浮；边框不参与布局，减少动态效果时取消位移动画。
- 右侧为六个标签和 `i-shuffle` 换组按钮，下方各展示三篇文章、三条最新评论。“再读一篇”标题旁的 `i-dice` 小图标随机打开一篇已发布且未隐藏的文章，避开当前页；入口沿用原生链接导航。站点图标库需要提供这两个图标。
- 767px 以下隐藏整个右侧内容区，不加载最新评论；扩大视口后补加载。储藏间的五个快捷入口紧凑并排；底部导航、版权、统计、运行时间和备案仍显示。
- 最底行两项备案及主题驱动按内容宽度居中排列；手机换行。
- 版权与备案两行的上方、行间、底部使用相同间距；宽屏左栏下方显示“最近落笔”的真实最新文章和发布日期，1200px 以下隐藏。
- 备案与必要文字继承原页尾字号。所有链接、访客统计和运行日期沿用配置，没有示例计数。
- 访客不足千时显示整数，千／百万以上使用 k／M／B 缩写，最多保留一位小数，悬停或键盘聚焦可查看完整人数。数字与本地占位均沿用线上蓝色 `#61afef`。缩写只影响显示，不改动统计原值；本地仍显示占位。
- 随机入口保留胶囊点击范围，无边框、底色和阴影，悬停时仅骰子旋转与提示“随机前往一篇文章”；标签换组轻淡入，减少动态效果偏好下禁用动效。桌面备案项之间以淡色点分隔，手机隐藏分隔点。

站点可通过 `footer.tagline` 配置签名，通过 `footer.navigation` 配置入口（键为 `menu` 的语言键，值为 URL）。未设置时使用站点副标题及归档／标签／关于入口。导航图标沿用现有图标库；RSS 取 `feed.rss.output`，GitHub 取 `social.github`，两者均仅显示图标，保留可访问名称。

`footer.ts` 在刷新时清理并重新绑定标签换组事件、重建运行计时器；本地预览不请求访客统计。`footer-comments.ts` 共用文本安全渲染、头像回退及空／失败状态；最新评论只读请求，已加载后不在页面切换时重复获取。
