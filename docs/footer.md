# 页尾

## 内容配置

站点在 `_config.shokax.yml` 的 `footer` 下配置；省略字段保留原有行为。

```yaml
footer:
  latest_post: true # 最近落笔，仍只在宽屏显示
  tags:
    enable: true
    limit: 6
  random_posts:
    enable: true
    limit: 3
  recent_comments:
    enable: true
    limit: 3
  navigation: # 按书写顺序显示；空对象 {} 隐藏快捷链接
    archives: /archives/
    friend-links: /friend-links/
    projects: /projects/
    guestbook: /guestbook/
    statistics: /statistics/
  social_links:
    rss: true # 地址来自 feed.rss.output
    github: true # 地址来自 social.github
```

`limit` 必须为正整数，无效值回退到标签 6、文章 3、评论 3；关闭使用 `enable: false`。标签首次展示与换组共用数量，评论请求与展示共用数量。文章／评论开关未填写或为 `null` 时兼容对应的 `widgets` 旧开关，明确设置 `true/false` 后不再依赖旧开关；最新评论仍需启用 Waline 或 Twikoo。所有开关均不改变现有移动端显示规则。

关闭文章或评论后另一栏自动填满；右侧全部关闭时取消空栏。社交入口关闭或没有地址时不展示，也不保留空分隔线。其他年份、签名、计数、运行时间和备案配置沿用原字段。

`layout/_partials/footer-discovery.pug` 渲染页尾，`source/css/_common/outline/footer/discovery.styl` 负责响应式样式。外层沿用正文宽度和侧栏预留空间，侧栏仍可固定显示到页面底部。

- 桌面左侧是站点名片、真实字数／阅读时长／访客数据和运行时间；运行天数与时分秒并排，版权位于备案信息上方居中。
- 左栏无独立底色，文字与下方导航对齐；整个页尾以低透明度的静态弧线、星点点缀，不参与鼠标交互。
- 三栏按预览样张加宽栏间距，统计数字略缩小，“最近落笔”使用次要字号与颜色；标签默认显示淡边框、小号数量，悬停或聚焦时强调颜色。
- “再读一篇”和“最近落笔”的标题只占一行，超长显示省略号，悬停可查看完整标题。文章／评论列表收紧条目高度与间隔，并减少标签区到列表、列表标题到内容的留白。
- 文章、最新评论和储藏间链接统一使用悬停淡入细线框、轻底色与 1px 上浮；边框不参与布局，减少动态效果时取消位移动画。
- 页尾站名沿用顶部 `font.logo` 字体及红青错位动画，静止时隐藏分色副层，仅悬停或聚焦时出现；浅色底使用普通混合模式以保留颜色，减少动态效果时隐藏副层。图标仍使用站点图标字体。快捷链接的悬停框收紧上下边距，手机保留触按高度。
- 右侧为六个标签和 `i-shuffle` 换组按钮，下方各展示三篇文章、三条最新评论。“再读一篇”标题旁的 `i-dice` 小图标随机打开一篇已发布且未隐藏的文章，避开当前页；入口沿用原生链接导航。站点图标库需要提供这两个图标。
- 导航不显示“储藏间”标题，直接从首个入口开始，保留无障碍区域名称。767px 以下隐藏整个右侧内容区，不加载最新评论；扩大视口后补加载。手机导航五个入口的图标与文字单行排列；RSS／GitHub 收拢在同一行右侧，以淡竖线分隔，均保留 44px 触按高度。长译名仅在导航内部滚动。底部导航、版权、统计、运行时间和备案仍显示。
- 最底行两项备案及主题驱动按内容宽度居中排列；手机两项备案并排，以淡点分隔，主题驱动独占下一行。窄屏备案文字适度缩小以容纳完整号码，各行保持 PC 的行高，去掉手机额外内边距与行间隔；导航区共用约 52px 最小高度，手机入口仍保留 44px 点击高度。
- 版权与备案两行紧凑排列，收回的行间距均分至虚线下方和页底留白，保持信息区总高度；宽屏左栏下方显示“最近落笔”的真实最新文章和发布日期，1200px 以下隐藏。
- 备案与必要文字继承原页尾字号。所有链接、访客统计和运行日期沿用配置，没有示例计数。
- 访客不足千时显示整数，千／百万以上使用 k／M／B 缩写，最多保留一位小数，悬停或键盘聚焦可查看完整人数。数字与本地占位均沿用线上蓝色 `#61afef`。缩写只影响显示，不改动统计原值；本地仍显示占位。
- 访客缩写单位、总字数的 `k/m` 和阅读时长的 `h` 统一使用主数值一半字号，右下方基线对齐；阅读时长不足一小时仍使用分钟单位，并沿用同款小号样式。访客不足千时只显示整数，不额外补单位。
- 文章入口停留 350ms 后只显示完整标题；最新评论显示“查看评论 · 页面名称”，匹配不到名称时仅显示“查看评论”，复用 `comment_entry.action` 译文。提示不展示 URL，实际链接保留评论定位锚点；键盘聚焦立即显示。标题使用生成时公开文章／页面的路径小表匹配，不额外请求。评论时间上的悬停提示仍为完整时间。
- 随机入口保留胶囊点击范围，无边框、底色和阴影，悬停时仅骰子旋转与提示“随机前往一篇文章”；标签换组轻淡入，减少动态效果偏好下禁用动效。备案项之间以淡色点分隔，手机隐藏主题驱动前的分隔点。

站点可通过 `footer.tagline` 配置签名，通过 `footer.navigation` 配置入口（键为 `menu` 的语言键，值为 URL）。未设置时使用站点副标题及归档／标签／关于入口。导航图标沿用现有图标库，“留言”使用顶部菜单同款 `i-message-board`；RSS 取 `feed.rss.output`，GitHub 取 `social.github`，两者均仅显示图标，保留可访问名称。

`footer.ts` 在刷新时清理并重新绑定标签换组事件、重建运行计时器；本地预览不请求访客统计。`footer-comments.ts` 共用文本安全渲染、头像回退及空／失败状态；最新评论只读请求，已加载后不在页面切换时重复获取。

Waline 最新评论显示原始 `time`，使用同一份 locale 与 `relativeTimeDays` 配置，并按评论区规则实时更新；悬停显示完整时间。身份标签优先取服务端公开 `label` / `type`，友链标签复用作者网站匹配与 `comment_friend` 文案、`friendBadge.colors` 配色，不按昵称推断身份。离开页面时清理时间刷新器。

最新评论昵称与身份标签组成同一组，时间靠右；长昵称或窄栏可自然换行。正文上方保留 4px 间隔，文章和评论共用最小行高；身份标签使用淡色底，保留作者与友链的颜色区分。
