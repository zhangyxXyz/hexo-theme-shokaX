# 标签详情视图

标签详情默认复用归档时间树：年份为折叠节点，月份为卡片，文章为叶子节点。宽屏中央轴交错排列，中等宽度和手机为左轴单列。单年份直接展开，多年份默认展开最近三个年份，并提供展开／收起全部按钮。

右侧图标胶囊支持「时间树／经典列表」双向切换，尺寸复用标签云、分类和归档控件。访客偏好保存在 `shokax.tag-detail.mode`，跨标签页和刷新保留，不影响标签云及归档的独立偏好。

```yaml
tag_view:
  mode: tree # tree | classic
  switchable: true
```

`switchable: false` 隐藏切换控件，忽略已保存的访客偏好。配置是主题默认值，站点可通过 `_config.shokax.yml` 覆盖。

时间树读取当前标签的完整文章集合，按站点时区分年、分月，日期倒序排列；经典列表保留 Hexo 原分页和链接。在经典第二页切到树形时仍展示完整标签，切回仍为第二页。每月超过 5 篇时独立分页，提供展开全部／返回分页，返回保留此前页码；控件、分页动画和年份折叠直接复用 `archive.ts`。

桌面首次悬停文章行 250ms 或聚焦标题显示摘要；已有摘要时移到另一行立即切换内容及高亮，不重复等待 250ms。点击摘要图标固定显示，再点关闭；悬停另一篇文章仍可接替当前浮卡。模型下拉操作不会固定摘要，离开浮卡及其菜单后恢复正常关闭。Esc、外部点击、滚动、切换视图和 PJAX 离页清理浮卡。窄屏／触摸设备使用摘要图标展开行内正文，标题始终直接跳转文章。

归档树和标签树通过 `archive-post-list.pug`、`article-preview.ts` 共用摘要。左侧使用文章 AI 摘要的星形标记，右侧复用 `summary_model_icon`、`summary_model_label` 和 `summary-picker`，可以切换模型及原文摘要。默认模型与文章页一致：先保留配置指定的版本，再排序展示；共享 `shokax.summary.article-model.v1` 偏好。模型缺失时使用该文章的默认模型，没有 AI 时依次提取 description、excerpt、渲染正文。纯文本最多 140 个 Unicode 字符，去除标题、代码、脚本、图片、表格和时效性提示；加密文章不输出摘要，不在悬停时请求接口。没有可用内容则不输出图标。

浮卡可进入共享模型菜单，菜单内的点击和键盘焦点不会错误关闭摘要。月内翻页、年份折叠、视图切换和 PJAX 离开会清理浮卡及其菜单。无 JavaScript 时保留配置指定的视图、原生年份和摘要折叠，显示完整月份，隐藏需要脚本的切换／批量操作。浅色、深色沿用主题变量，减少动态效果时禁用新增过渡。

归档与标签详情的文章高亮共用 `article-preview.styl`：8px 圆角、上下各 4px 留白、4% 主题色透明底和 150ms 渐变。悬停、键盘焦点、摘要打开时使用同一高亮，不改变分隔线，也不裁切浮卡；减少动态效果时取消渐变。

条目采用稍紧凑的 2.75rem 最小行高、上下 .3rem 内边距和 1.65 标题行距；摘要图标为 .8rem。触屏继续保留 2.75rem 的预览点击区域，长标题自然换行。

验证：`pnpm test`、`node toolbox/test-tag-detail.mjs`；从博客根目录执行 `pnpm run build:local`。浏览器重点核对桌面悬停、390px 摘要展开、年份折叠、经典分页和 PJAX 往返。

正文折叠样式限定为 `.md details > summary`，避免 PJAX 保留 `post.css` 后给年份及摘要按钮附加灰底、箭头和内边距。回归时需从文章页点击进入标签／归档，不能只验证直接打开页面。标签篇数放在标题旁；标题右下方的展开／收起所有年份按钮与归档位置一致，单年份同样提供。年份胶囊不使用强调底色。
