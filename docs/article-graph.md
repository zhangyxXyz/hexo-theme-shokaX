# 文章双向引用图

构建期从公开文章的已渲染正文中解析真实链接，建立出链与反向索引。文章 A 链接 B，A 的「本文引用」出现 B，B 的「引用本文」自动出现 A。标签、分类和推荐列表不参与建边；无需修改现有 Markdown，也不额外解释 `[[Wiki 链接]]`。

## 配置与范围

```yaml
article_graph:
  enable: true
  max_nodes: 50
  domain_aliases: [https://example.com]
vendors:
  js:
    d3: { source: jsdelivr, url: npm/d3@7.9.0/dist/d3.min.js }
```

主题默认关闭，本站覆盖开启。`article_graph: false` 只隐藏某篇文章的组件；`graph_index: false` 将该文章及相关边移出公开索引。草稿、隐藏、加密文章及有效标签密码继承均不纳入图；`password: ''` 按加密插件规则显式豁免。未来文章遵循 Hexo 的发布配置。

文章身份使用最终 `post.path`；URL 解析保留路径大小写，支持配置的域名别名、部署子目录、相对链接、中文编码、查询参数/锚点与 `index.html` 别名。重复、自链、代码示例、无效目标和站外 URL 不建边。每次 `before_generate` 在正文渲染结束后重建整个索引，包括命中缓存的文章；不依赖 `after_post_render` 是否再次触发。

## 页面与资源

模板在赞赏之后、继续阅读之前输出引用列表及当前文章的一跳 JSON 数据。正文末尾使用统一信息栏：标签独占第一行并自然换行，分隔线居中，更新／阅读信息位于第二行，桌面右对齐、窄屏左对齐。版权位于延伸阅读之后、评论入口之前。标题左侧使用站点已有的 `i-graph`。数据通过安全转义的 `application/json` 脚本传递，标题与 URL 不用 `innerHTML` 拼接。无关系时不生成空组件。超过上限时，图最多显示 50 个节点，完整引用列表仍可访问。

浏览器在组件进入视口或读者展开时加载 `vendors.js.d3`，现场用 D3 force 计算布局并创建 SVG。布局手动计算后停止模拟；不在后台持续消耗动画帧。蓝色表示入链，玫瑰色表示出链，紫色表示互引，箭头表达实际引用方向。节点多于 12 个时仅常显当前文章标题，其余通过悬停、键盘聚焦或引用列表查看。

组件沿用主题底色和弱边框，关联数量不包含当前文章；工具栏与标题并列，图例仅展示当前图实际存在的关系。少量节点采用横向展开的初始布局，画布高度 15rem；密集图保留 19rem。鼠标点击画布不显示浏览器默认外框，键盘聚焦显示主题色细描边。

动态 SVG 节点通过 `data-theme-tooltip` 接入通用提示，使用 `aria-label` 保留完整标题，不生成会触发原生白色提示框的 SVG `title`。画布操作说明通过 `aria-describedby` 关联可见帮助文字；通用提示负责悬停、键盘聚焦、模态顶层和 PJAX 清理。

引用列表用方向图标、数量和淡底分组展示入链／出链，折叠入口使用 `i-angle-right`，展开与收起采用 220ms 高度过渡，尊重减少动态效果设置并在 PJAX 离开时取消动画。条目复用归档／标签页的 `articlePreview` 模板、`article_preview` 数据助手及 `refreshArticlePreviews` 交互：桌面悬停或键盘聚焦显示摘要，触屏可点击预览图标；支持已缓存的 AI 摘要模型切换，无摘要时显示原文摘录。正文末尾的分隔线位于标签与更新／阅读信息之间，上下各留 .85rem；无标签时不添加这条线。

引用列表默认展开。入链／出链各自超过 5 篇时显示上一页、页码、下一页和「展开全部」；恢复分页时保留原页，翻页先关闭摘要浮层。分页仅隐藏已有条目，全部链接保留在 HTML 中，无 JavaScript 时仍可完整阅读。引用条目最小行高 2.25rem、间距 .1rem；共享归档／标签时间线最小行高为 2.75rem，缩小预览图标但保留触屏点击区域。

支持拖动画布、缩放按钮、重置、弹窗放大以及节点链接；聚焦画布后可用方向键平移、`+` / `-` 缩放、`0` / Home 重置。Ctrl / Command + 滚轮缩放，普通滚轮保留页面滚动。手机默认收起图，可手动展开，仅常显当前标题，其他文章通过完整引用列表阅读，避免长标签重叠；弹窗内支持单指平移。引用列表始终由 HTML 提供，绘图库加载失败时可以重试。未验证多指缩放，当前也没有实现节点拖拽。

节点标题按 SVG 当前屏幕变换补偿字号，保持约 13 CSS px，不随 viewBox 自动适配、缩放或放大弹窗变成大标题。标签显示宽度按画布宽度限制在 100–220px，使用实际文本测量省略超出部分，完整标题仍保留在悬停提示和辅助技术标签中。尺寸变化通过 ResizeObserver 更新，PJAX 销毁时清理；平移不重复测量。此轮仅完成源码修改和无输出类型检查，按用户要求未重建，浏览器效果待其他任务统一重建后验证。

PJAX 离开和重复初始化时撤销事件、断开观察器、关闭弹窗、清理拖动与定时器；未完成的共享绘图库加载可以供下一页复用，但不会再操作离开的组件。SVG 节点与 HTML 引用链接都交给现有 PJAX；导航解析读取 `href` 属性以兼容 SVGAnimatedString。

本站通过 `node toolbox/resource-localization/index.mjs download --only js.d3 --apply` 下载 D3 7.9.0，文件位于 `source/resource/static/npm/d3@7.9.0/dist/d3.min.js`。local 环境使用 `/resource/static/` 副本，production 使用配置的自有 CDN。下载保留上游版权头，不执行 CDN 上传。扫描器标出的动态请求表达式属于 D3 通用数据读取 API；本组件只使用 force 布局，不调用这些数据读取 API。

## 验证

摘要浮卡在触发位置的标题被截断时，首行补充文章完整标题（SVG 标签比较原始名称，HTML 链接检查实际裁切尺寸）。浮卡内标题仍是单行，宽度不足时由 CSS 显示省略号，不改文章名称、不额外加宽浮卡；原位置未截断时不重复展示标题。

在博客根目录运行：

```powershell
node themes/shokax-src/toolbox/test-article-graph.mjs
node themes/shokax-src/toolbox/test-article-graph-loader.mjs
node themes/shokax-src/toolbox/test-navigation.mjs
pnpm --dir themes/shokax-src test
pnpm run build:local
```

测试覆盖 URL/方向/互引、隐私过滤、缓存文章改链及删文后的重建、数量上限、模板转义、语言和 SVG 导航。本站 2026-09-26 生成快照为 38 条有向引用，37 篇文章显示组件；`posts/29404.html` 有三条入链，`posts/50504.html` 有 32 条出链。浏览器检查包含窄屏折叠与按需加载、明暗主题、放大关闭和 PJAX 节点跳转。样式调整后复核 `posts/15006.html` 与 `posts/50504.html`，确认鼠标点击无外框、键盘聚焦为主题色 1px 描边、关联数量及图例正确。
