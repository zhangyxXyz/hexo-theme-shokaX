# 无刷新切页

设置 `modules.pjax: true` 启用同源 HTML 页面导航。主题默认关闭，本站 YAML 已开启。
页面可通过 front matter `pjax: false` 关闭；链接可用 `data-pjax="false"` 或 `data-no-pjax` 绕过。
跨站、下载、新窗口、修饰键点击和当前页面锚点保持浏览器原生行为。

`source/js/_app/pjax/navigation.ts` 替换品牌标题、头图、正文、目录／关联侧栏及前后篇入口，
保留全局工具栏、音乐播放器、audio 和看板娘。每次更新标题、页面配置、SEO 元数据并补载缺失样式。
正文脚本按顺序重新执行，加密文章的 HBE 入口重新绑定密码表单。
新增需要整页初始化的第三方组件时应检查其销毁及重入行为，或将该页设为 `pjax: false`。

生命周期沿用 `pjax:send` → `siteRefresh` → 页面脚本 → `pjax:complete`。
切换时销毁旧评论实例、关闭弹窗；新评论使用新 pathname 初始化。
请求失败、布局不兼容或页面主动关闭 PJAX 时回退整页加载，因此这些情况会中断音乐。
后退／前进重新获取页面并恢复滚动位置，不缓存已解密正文。
新请求取消旧请求，DOM 更新顺序执行；被后续导航取代的初始化不触发统计。

切页时先批量完成 DOM 增强，再统一计算视口和恢复位置，避免在多个组件之间反复强制布局。
首次加载和 PJAX 都在正文初始化后立即定位，不再固定等 500ms 后重新滚动。
`components/page-entry.ts` 在初始化和定位完成、蒙层开始淡出时协调正文、页头标题与活动侧栏的进场。
普通链接访问沿用旧站正文／侧栏 80px／500ms 上移淡入，页头标题 18px／300ms 下移淡入；
明确的锚点和前进／后退恢复仅淡入正文，保证目标坐标稳定。普通链接恢复自动保存的阅读位置时仍保留上移动画。
输入、下一次导航或隐藏页面取消入场动画，600ms 内释放全部动画与监听；减少动态效果时仅用 120ms 淡入。
位移动画会改变 `getBoundingClientRect()` 却不触发 ResizeObserver，不能用动画中的位置恢复锚点。
上移动画期间跳过偏移校正，结束后通过一次事件检查真实布局；没有布局变化就不再次滚动。
`pjax/scroll-restoration.ts` 随后仅在正文／页头尺寸、图片加载、字体或解密事件发生时检查偏移，
同一帧合并一次；阅读位置固定当前可见正文块，明确的锚点保持标题与导航栏的间距。
页面尚不够长时暂不固定正文块，等异步内容到达后尝试恢复原坐标。
浏览器已自动补偿的位移不再重复处理；评论深链接和归档自己的锚点动画保留各自流程。
正文标题使用 `scroll-margin-top: 4rem`，原生 hash、目录点击和脚本定位共用留白，
避免整页加载后的原生定位把标题藏在导航栏后面；`load`／`pageshow`／`resize` 也在上述有限窗口内合并检查。

校正窗口最多 2.5 秒、最多 8 次移动，无轮询、无阻塞资源等待。滚轮、触摸、鼠标按下、导航按键、
切页、改变锚点或隐藏页面立即取消，清除 observer、监听、定时器和待执行帧。
视口变化只触发有上限的布局检查，不作为用户输入取消：首次加载的滚动条调整也可能产生 resize。
用户输入在异步初始化期间也有效；校正结束后交还浏览器，不能保证任意晚到的内容仍精确定位。
数学复制模块复用初始化 Promise，无图文章不创建图片查看器，有图文章在代码块等 DOM 增强之后初始化查看器。
本机 19k 字、约 3900 个正文节点的长文样本，`siteRefresh` 从约 123ms 降至 32–34ms；
这是本地同一浏览器的抽样结果，不代表所有设备或页面的性能。临时计时日志已移除。

## 加载过渡

直接替换默认 `_partials/loading.pug` 和 `third-party/loading.styl`，星环、六颗轨道星点、中心光点及渐变细线
参考 [Lavender 的加载效果](https://blog.lavender816.top/posts/3257086419/)，使用本站标题、副标题。
配色沿用主题粉色系并略微提亮：中心由浅樱粉 `#f5afc9` 过渡到柔粉 `#f084ae`，深色模式终点使用 `#ed80aa`。
圆环和光晕沿用同一粉色系，不透明度分别为 24% 和 12%，降低快速切页时的视觉存在感；薄荷青 `#8fcfc8` 仅点缀两颗轨道星点和一段圆弧，不再混入紫色。
标题保持单色：浅色模式使用柔粉 `#f084ae`，深色模式使用暖浅粉 `#f3aac6`。
强制对比度模式使用系统文字色。
底部细线为居中的同色系粉色渐变，中部实色、两端淡出，没有紫蓝色段或移出容器的动画空档。
颜色集中在默认 loading 样式的 `--loader-*` 变量；明暗蒙层使用 95% 不透明度，
保留 8px 磨砂，减少底下页头和波浪对颜色的干扰。中心呼吸仅轻微缩放，不改变透明度。
`loader.start` 控制整页首次加载，`loader.switch` 独立控制 PJAX；`loader.scope` 为 `content`（默认正文列）
或 `viewport`（整屏磨砂）。可选 `loader.title`／`loader.subtitle` 覆盖文案，空副标题隐藏。

加载层保留当前内容，请求发出时出现、完成后淡出；最短 180ms 只约束遮罩显示，DOM 更新与定位不等待它。
蒙层开始淡出时启动正文进场，避免正文动画在蒙层背后提前播完；本站启用 viewport 整屏半透明磨砂蒙层。
旧请求的完成回调不能关闭新请求的遮罩，连续点击会复用同一加载节点；失败沿用整页导航回退。
JS 设置 15 秒释放上限，初始 CSS 另有失效兜底；遮罩不拦截操作，滚轮／触摸可立即取消。
只用短时 backdrop-filter 与 CSS transform/opacity 动画，不加 Canvas、常驻逐帧任务或动画依赖。
隐藏页面暂停星环动画，加载完成后隐藏节点；切换标签页不再触发切页 loading。

## 访问统计

- Waline 由 `visitor.enable: true`、`visitor.type: waline` 的独立入口维护，每次页面初始化完成增加一次。
  不要求打开评论面板；评论客户端保持 `pageview: false`，避免重复递增。
  同一正文节点反复初始化不重复计数；离开后返回形成新的访问。
- 百度统计使用 `visitor.baiduAnalytics` 中的站点 ID。初次文档由 `hm.js` 上报；
  成功切页后补 `_trackPageview(pathname + search)`，同页锚点不额外上报。
- `visitor.baiduSpa: manual` 为默认模式。如果百度后台已经开启自动 SPA 跟踪，设为 `auto`，
  主题不再手动上报，防止重复。配置方式见
  [百度官方 SPA 说明](https://tongji.baidu.com/web/help/article?id=324&type=0)。
- `visitor.readOnly: true`、本机及非正式主机访问不递增 Waline，也不上报百度。
  本站 local 环境另外显式关闭百度 ID；production 沿用旧站 ID。

验证：主题 `pnpm test`、`node toolbox/test-navigation.mjs`、`node toolbox/test-visitors.mjs`、
`node toolbox/test-scroll-restoration.mjs`（异步布局、原生锚定、用户中断、过期回调、连续反馈上限）；
`node toolbox/test-page-transition.mjs` 覆盖独立开关、连续导航、过期完成回调、超时及输入取消、稳定锚点和减少动画。
浏览器验证首页／文章及前进／后退时音乐连续，统计递增与百度队列通过模拟请求验证。
滚动改动另实测中文标题深链接／整页刷新、目录点击、跨页后退／前进恢复、`/friend-links/#42` 评论抽屉定位；
标题停在顶部 64px 留白，历史坐标往返一致，未观察到 ResizeObserver 循环或导航异常。
本地预览不写线上访问数据；正式站真实上报仍需部署后验证。
